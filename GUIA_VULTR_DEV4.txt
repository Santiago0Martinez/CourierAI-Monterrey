💡 EXPLICACIÓN RÁPIDA (PARA ENTENDER EL "SUDO" EN WINDOWS):
--------------------------------------------------------------------------------
Tu laptop personal tiene Windows 11 y NO necesitas instalar Linux en ella.
Vultr es una computadora remota en la nube que sí corre Linux (Ubuntu). 
Lo que harás desde tu Windows 11 es "controlarla a distancia" mediante SSH.
Cuando te conectas por SSH, tu terminal de Windows se convierte en la pantalla
de la máquina Ubuntu de Vultr, y por eso ahí ADENTRO sí se usan los comandos
"sudo" y "apt".

================================================================================
PASO 0: QUÉ DATOS NECESITAS DE TU PANEL DE VULTR
================================================================================
Entra a tu cuenta en https://my.vultr.com/ y entra a tu servidor (Cloud Compute).
Anota estos 2 datos que aparecen en la pantalla de Vultr:
1. IP del Servidor (ejemplo: 207.246.120.45)
2. Password del usuario "root" (Vultr te da un botón de 'Copy Password' o un ojito)

================================================================================
PASO 1: CONECTARTE AL SERVIDOR DESDE WINDOWS 11
================================================================================
1. En tu laptop Windows 11, presiona la tecla Windows, escribe "PowerShell" y ábrelo.
2. Escribe el siguiente comando (sustituye por la IP real de tu servidor Vultr):

   ssh root@TU_IP_DE_VULTR

   Ejemplo:
   ssh root@207.246.120.45

3. Si te aparece una pregunta como: 
   "Are you sure you want to continue connecting (yes/no/[fingerprint])?"
   Escribe: yes  (y presiona ENTER).

4. Te pedirá: "root@... password:"
   - Copia la contraseña desde Vultr.
   - En PowerShell, haz CLIC DERECHO para pegarla (OJO: por seguridad en Linux 
     NO se ven asteriscos ni letras al pegar la contraseña, parece que no escribe, 
     pero sí se pega).
   - Presiona ENTER.

¡Listo! Ya verás en tu terminal algo como: "root@vultr:~#"
Ahora todo lo que escribas se ejecutará dentro de Ubuntu.

================================================================================
PASO 2: INSTALAR PYTHON Y GIT EN EL SERVIDOR
================================================================================
Copia y pega este comando en la terminal conectada a Vultr y dale ENTER:

sudo apt update && sudo apt install -y python3-pip python3-venv git

(Esperar unos 30-40 segundos a que termine de descargar).
